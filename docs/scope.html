Executive Summary

What we're doing and why

Summary

Beyond (BBY US, Overstock, BuyBuyBaby) runs mission-critical marketing and e-commerce operations across three brands. This scope fixes a live, undiagnosed MCP implementation while building a parallel Data 360 (Data Cloud) foundation to feed enriched, unified customer data into MCP and paid-media activation. Two concurrent tracks — MCP Next remediation and Data 360 build-out — on a shared 24-week waterfall calendar. The program adds Acxiom enrichment, 5 ad-platform connectors, web experience personalization, and Braze integration. The aim is a low-disruption, high-confidence remediation that upgrades Beyond's Salesforce footprint without service disruption.
